# Análise de risco de crédito com Python

Este projeto é uma análise exploratória de uma base de crédito. A ideia é entender o perfil dos clientes, padrões de inadimplência e fatores que podem estar relacionados ao risco de crédito.

Usei Python para limpar os dados, criar variáveis, analisar indicadores de risco e gerar visualizações simples para apoiar uma leitura de negócio.

## Perguntas que quero responder

- Qual é a taxa geral de inadimplência?
- Qual é o perfil dos clientes inadimplentes?
- Como renda, idade e valor do empréstimo se relacionam com inadimplência?
- Existe diferença de risco por finalidade do empréstimo?
- Clientes com maior comprometimento de renda têm maior inadimplência?
- Quais pontos poderiam apoiar uma análise inicial de crédito?
